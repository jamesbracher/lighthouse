# Lighthouse

A tiny text adventure set in a lighthouse. Next.js and TypeScript, deployed to
Cloudflare Workers with the OpenNext adapter.

- `npm run dev` runs the app locally.
- `npm run preview` builds with OpenNext and runs it in the Workers runtime.
- Every push to `main` deploys via GitHub Actions.

The original plain HTML, CSS and TypeScript prototype lives in `prototype/` as a
design reference.
